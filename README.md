# IZV — Project 3: Geospatial Accident Analysis

A geopandas look at wildlife collisions in Jihomoravský kraj, Czechia.

- Builds GeoDataFrames (S-JTSK → WGS84) and draws basemaps via contextily
- Clusters collision hotspots with scikit-learn and plots them on OSM tiles
